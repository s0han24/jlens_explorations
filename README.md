# Understanding Mech Interp Through J-Lens

This repository contains my explorations of the various tools used for Mech Interp with the short term goal of Replicating the J-Lens on smaller models from scratch. I have the compute to comfortably run forward and backward passes on models with upto 8 billion parameters which is much smaller than the models that have been shown to replicate the J-Space (At least as far as I know, it has been replicated for Qwen3 27B as part of a well known public review of Anthropic's paper). I would expect much noisier results with clean replication only on a select few cases given that the models are simply less capable. You wouldn't expect the global workspace of an orange cat to make as much sense as that of a human, right?
